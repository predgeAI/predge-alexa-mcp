MCP tool calls (live)

Each tool call the agent makes to /mcp shows up here with its structured result. The receipt card on the left is an MCP App (ui://kept/receipt).
Merchants and confirmations in this demo are generic samples, labelled as samples. Verdicts are deterministic checks of a confirmation against what was promised, signed by Predge (ed25519) and verifiable offline with the open-source predge-verify library. If the server has no Predge key, checks run on a clearly labelled offline sample path and are unsigned.
